Backup dos dados

Faça um backup regularmente para não perder suas ruas e entregas se limpar os dados do navegador ou trocar de aparelho.

A restauração substitui os dados atuais pelos dados do arquivo escolhido. Faça um backup antes de restaurar.

Sobre o modo offline

Esta versão usa armazenamento local do navegador e pode abrir sem internet depois que o site for hospedado em HTTPS e carregado pelo menos uma vez. Para funcionar offline, o arquivo do site precisa estar publicado com o service worker ativo.

Não use a prévia do construtor como única cópia. Faça backups e teste em modo avião antes de depender do app no trabalho.
